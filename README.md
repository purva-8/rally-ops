# RallyOps

Tournament management app for badminton (and more). Run brackets, manage courts, track live scores, and handle player registration — all in one place.

## Routes

- `/rallyops` — Organizer home (set up tournament)
- `/admin` — Admin dashboard (password-gated)
- `/tournament` — Player registration
- `/tournament/brackets` — Public brackets view
- `/tournament/leaderboard` — Live leaderboard

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
